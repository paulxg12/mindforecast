The point of this project. Redshift alone classifies SDSS objects almost perfectly (0.925 macro F1 from a single feature), because stars have redshift ~ 0 and extragalactic objects do not. Reporting only that number would be misleading. So the pipeline runs two experiments: a photometric model that sees only what an imaging survey sees, and a spectroscopic model that also gets redshift. The interesting result is the gap between them.

Dataset

99,999 spectra after dropping rows with unobserved bands. Classes: GALAXY 59,445, STAR 21,593, QSO 18,961. Identifiers (obj_ID, plate, MJD, ...) are dropped: they describe the observation, not the object. Right ascension is encoded as sin/cos so the 0/360 wrap does not create a false distance, and four adjacent-band colours are added.

Experiment A - photometric only

Five band magnitudes, four colours and sky position. This is what a survey can do before any follow-up spectrum is taken, so it is the hard, useful problem.

Model comparison

All learners beat the majority-class baseline of 0.249 macro F1. Tree ensembles gain the most from redshift, and the logistic model does surprisingly well on colours alone - the class boundaries in colour space are close to linear, which matches the astrophysics.

Reproducing

Split: stratified 20% held-out, seed 0. Hyperparameters are fixed in skyclass/models.py; nothing is tuned on the test split. Reported metrics are single-split estimates, not cross-validated ones.
